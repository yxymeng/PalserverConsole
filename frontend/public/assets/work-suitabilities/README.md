图标属于 Pocketpair 的游戏美术素材，不属于本项目自行创作的 MIT 授权代码。本目录不授予这些素材的再分发许可；公开分发或商业使用前需另行确认授权。

中文名称与图片路径只维护在 `frontend/src/features/world/palWorkSuitabilities.ts`，不要建立第二份运行时映射。文件名编号不能根据技能枚举顺序推断：`08` 为制药、`09` 为原油提炼、`10` 为冷却、`11` 为搬运、`12` 为牧场。`00–07` 依次为生火、浇水、播种、发电、手工作业、采集、伐木、采矿。未映射的 `13` 和 `90` 没有复制。

原始图片均为 RGBA，原油提炼为 40×40，其余为 64×64；列表卡片以 12×12、详情弹窗以 16×16 CSS 像素显示，明暗主题均保留原色，两处使用同一张名称/图片路径表。下拉框仍只显示中文；未知技能仍使用通用 SVG，列表保留原标识和等级，详情保留“工作类型未收录”及等级提示。不得把 FModel 的本机安装目录作为运行时依赖。
