# M0 本地脱敏样本

`sanitized/level.m0.json.gz` 只能由 `backend/tools/create_sanitized_fixture.py`
从本机真实 `Level.sav` 生成。它是压缩的、值已脱敏 JSON 结构快照，不是可用于恢复的 SAV。
该目录中的所有本地样本均被 Git 忽略，不能提交、打包或公开分发。

生成工具会：

1. 以只读方式读取源文件；
2. 对 `PlM` 存档仅在显式传入本机已有 `libooz.dll` 路径时解压，绝不复制该 DLL；
3. 将非结构化字符串和 UUID 替换为匿名值，同时保留关联关系；
4. 对原始 Level.sav 再次解析两次；
5. 成功后将输出文件标记为只读。

上游 `palworld-save-tools==0.24.0` 当前无法稳定写回本机新版未知 UUID 结构，
所以 M0 不伪造 SAV 往返成功。该样本仅用于结构回归验证，不用于启动服务器、恢复存档
或任何游戏内写操作。

M5 在同一 Git 忽略目录生成 `sanitized/level.m5.json.gz`。它使用 M5
2026-07 只读兼容层展开角色、物品槽、角色容器、工会、据点和工作容器的
详细字段，再对字符串及标准库/第三方 UUID 类型统一匿名化。该文件仍只用于
本机回归，不得提交、打包或公开分发。
